# Persistencia_PFE

## Atividade 4 - Geolocation, localStorage e Drag and Drop

Projeto desenvolvido para a atividade de Persistência PFE.

## Funcionalidades

- Geolocalização utilizando a Geolocation API
- Exibição de latitude e longitude
- Persistência da localização utilizando localStorage
- Exibição da última localização salva
- Mapa interativo utilizando Leaflet e OpenStreetMap
- Marcador da localização atual
- Drag and Drop
- Exclusão da localização ao arrastar o papel para a lixeira

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Geolocation API
- LocalStorage
- Drag and Drop API
- Leaflet
- OpenStreetMap
- Tailwind CSS

## Como executar

1. Abra a pasta no VS Code.
2. Instale a extensão Live Server.
3. Abra o `index.html` com **Open with Live Server**.
4. Permita o acesso à localização quando o navegador solicitar.
